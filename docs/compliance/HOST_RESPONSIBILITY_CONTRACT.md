# Host responsibility contract

**Contract version:** 1.0.0

**Machine-readable form:** [`host-responsibilities.v1.json`](host-responsibilities.v1.json)

The deploying organization must implement every `required` item and retain the evidence described in the JSON contract for the full period during which it explains retained accounting records. Installing the package does not satisfy these controls.

The contract covers personal privileged identities and MFA, least privilege and access reviews, separation of application/migration/administration roles, independently permissioned immutable evidence storage and audit anchors, synchronized time, encrypted backup and tested restore, monitored verification, incident handling, release identity, and data-location/subprocessor documentation.

Any exception must name an owner, affected legal entities and periods, compensating controls, approval, expiry, and evidence. A certification or readiness scope must pin this contract version together with package, database, storage, queue, configuration, migration, and host versions.
